====================================================================
GUIA DE CONFIGURACION DE SUPABASE Y GEMINI AI (SIN CLI - DESDE EL PANEL WEB)
====================================================================

Esta guia explica paso a paso como configurar la Edge Function y la clave secreta de Gemini en Supabase usando unicamente el panel web, sin necesidad de CLI.

--------------------------------------------------------------------
PASO 1: AGREGAR EL SECRET (API KEY DE GEMINI)
--------------------------------------------------------------------
1. Abre tu panel de Supabase:
   https://supabase.com/dashboard/project/qqjhadwxboeichxtxree

2. En el menu lateral izquierdo, ve a:
   Project Settings -> Edge Functions -> Secrets
   o Configuration -> Secrets

3. Haz clic en "Add new secret".

4. Llena los campos:
   - Name: GEMINI_API_KEY
   - Value: [Tu clave API de Google AI Studio / Gemini]

5. Haz clic en "Save".

--------------------------------------------------------------------
PASO 2: CREAR Y DESPLEGAR LA EDGE FUNCTION ("gemini-chat")
--------------------------------------------------------------------
1. En el menu lateral de Supabase, entra a "Edge Functions".
2. Haz clic en "Create Function" / "New Function".
3. Nombre de la funcion: gemini-chat
4. En el editor web de codigo para index.ts, pega el siguiente codigo:

import { serve } from "https://deno.land/std@0.168.0/http/server.ts";

const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
};

serve(async (req) => {
  if (req.method === 'OPTIONS') {
    return new Response('ok', { headers: corsHeaders });
  }

  try {
    const { prompt, image } = await req.json();
    const apiKey = Deno.env.get('GEMINI_API_KEY');

    if (!apiKey) {
      return new Response(
        JSON.stringify({ error: 'GEMINI_API_KEY no configurada' }),
        { status: 500, headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
      );
    }

    const url = `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=${apiKey}`;

    const contents = [];
    const parts = [];

    if (image && typeof image === 'string' && image.includes('base64,')) {
      const mimeType = image.substring(image.indexOf(':') + 1, image.indexOf(';'));
      const base64Data = image.split(',')[1];
      parts.push({
        inline_data: {
          mime_type: mimeType || 'image/jpeg',
          data: base64Data
        }
      });
    }

    parts.push({ text: prompt || 'Hola' });
    contents.push({ parts });

    const response = await fetch(url, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ contents })
    });

    const data = await response.json();
    const reply = data.candidates?.[0]?.content?.parts?.[0]?.text || 'No pude procesar la respuesta.';

    return new Response(
      JSON.stringify({ reply }),
      { headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
    );

  } catch (error) {
    return new Response(
      JSON.stringify({ error: error.message }),
      { status: 500, headers: { ...corsHeaders, 'Content-Type': 'application/json' } }
    );
  }
});

5. Haz clic en "Deploy".

--------------------------------------------------------------------
PASO 3: BASE DE DATOS EN SUPABASE (OPCIONAL)
--------------------------------------------------------------------
En SQL Editor en tu panel de Supabase:

CREATE TABLE IF NOT EXISTS knowledge (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  type TEXT NOT NULL,
  title TEXT NOT NULL,
  content TEXT NOT NULL,
  url TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE knowledge ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public full access" ON knowledge FOR ALL USING (true);
