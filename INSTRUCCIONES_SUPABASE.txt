====================================================================
GUIA DE CONFIGURACION DE SUPABASE Y GEMINI AI (SIN CLI - DESDE EL PANEL WEB)
====================================================================

Esta guia explica paso a paso como configurar la Edge Function y las Tablas de Supabase usando los archivos separados SUPABASE_FUNCTIONS.ts y SUPABASE_SCHEMA.sql.

--------------------------------------------------------------------
PASO 1: AGREGAR EL SECRET (API KEY DE GEMINI)
--------------------------------------------------------------------
1. Abre tu panel de Supabase:
   https://supabase.com/dashboard/project/qqjhadwxboeichxtxree

2. En el menu lateral izquierdo, ve a:
   Project Settings -> Edge Functions -> Secrets
   o Configuration -> Secrets

3. Haz clic en "Add new secret".

4. Llena los campos:
   - Name: GEMINI_API_KEY
   - Value: [Tu clave API de Google AI Studio / Gemini]

5. Haz clic en "Save".

--------------------------------------------------------------------
PASO 2: CREAR Y DESPLEGAR LA EDGE FUNCTION ("gemini-chat")
--------------------------------------------------------------------
1. En el menu lateral de Supabase, entra a "Edge Functions".
2. Haz clic en "Create Function" / "New Function".
3. Nombre de la funcion: gemini-chat
4. Copia el codigo completo del archivo:
   SUPABASE_FUNCTIONS.ts
   y pegalo en el editor web de Supabase para index.ts.
5. Haz clic en "Deploy".

--------------------------------------------------------------------
PASO 3: CONFIGURAR TABLAS Y PERMISOS EN LA BASE DE DATOS
--------------------------------------------------------------------
1. En el menu lateral de Supabase, abre "SQL Editor".
2. Crea una nueva consulta (New Query).
3. Copia el codigo SQL completo del archivo:
   SUPABASE_SCHEMA.sql
   y pegalo en el editor SQL.
4. Haz clic en "Run" para ejecutar las sentencias y crear las tablas con permisos completos (Lectura, Insercion, Edicion y Eliminacion).
